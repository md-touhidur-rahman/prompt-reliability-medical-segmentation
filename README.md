# Prompt Reliability in Language-Guided Medical Image Segmentation

Reproducibility and manuscript repository for a study of case-level
prompt sensitivity in language-guided medical image segmentation.

The repository contains:

- frozen manuscript source data;
- publication figures and figure-source CSV files;
- manuscript tables;
- Brain600 and Breast113 reliability analyses;
- controlled prompt-sensitivity analyses;
- prompt-interface analyses;
- frozen development/held-out evaluation records;
- prompt definitions and experiment manifests;
- provenance and reproducibility records.

## Important

Raw medical-image datasets and model checkpoints are intentionally
excluded from this repository.

The analyses distinguish dataset-level segmentation performance from
case-level reliability under language variation.

This repository is initially maintained as a private publication
snapshot. Documentation will be expanded before public release.
